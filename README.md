# Pulse Landing Page

A modern, high-performance landing page built with React, Vite, TypeScript, Three.js, and Tailwind CSS.

## 🚀 Features

- **Dynamic Hero Section**: Immersive visuals and sleek typography.
- **Interactive 3D / Animations**: Powered by Three.js, React Three Fiber, and Tailwind CSS.
- **Responsive Design**: Optimized for all viewports and device types.
- **Custom Design System**: Styled with Tailwind CSS and Radix UI components.

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or bun

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
